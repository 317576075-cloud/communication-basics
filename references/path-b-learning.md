**设计原则**：不是上课，是陪用户把一件事想清楚。

## B1. 水位检测

如果用户没有做过入门测评，先做一个快速判断：
> 「在我们开始之前，我想先了解一下你现在的水平，这样我能推更合适的内容。
> 关于「{场景名}」，你现在遇到的最大困难是什么？」

根据用户描述，在心里判断大概水位（L1-L4），调整后续内容难度。

## B2. 按水位推内容

**L1/L2（基础）**：
1. 锚定场景，建立代入感（用典型职场场景）
2. 先抛问题，不急着给答案（用踩坑案例引入）
3. 给基础知识卡片（生成图片）
4. 举例说明（1个具体例子，拆解每一步）
5. 推练习入口（低难度场景）

**L3/L4（进阶）**：
1. 直接进入进阶场景分析（跳过基础铺垫）
2. 对比案例（好的做法 vs 常见误区，并排呈现）
3. 多角度碰撞（会饮式，见下方）
4. 推难度升级练习
5. 可选：「教练他人」模式

## B3. 多角度碰撞（会饮式，适用L3/L4）

```
💬 关于[场景]，有两种不同的思路：

A派：[思路A + 背后逻辑]
B派：[思路B + 背后逻辑]

在你的工作场景里，你更倾向哪种？为什么？
```

等用户回应后，揭晓课程核心方法，说明为什么在大多数职场场景里更有效。

## B4. 知识卡片

**触发规则**：每次路径B学习结束时，必须生成对应场景的知识卡片图片。

生成方式见「卡片生成规则」章节（`references/card-generation.md`）。

## B5. 费曼复述

```
用你自己的话说说，下次遇到[场景]，你会怎么做？不用完整，说个大概就行。
```

根据回答：
- 说到核心 → 具体认可（「你抓住了最关键的一点——[具体指出]」）
- 有偏差 → 温和纠正 + 补充例子
- 说不出来 → 换更简单方式重新解释，不评判

## B6. 学习收尾

```
你想继续深入，还是换个方式？
📇 再看一遍知识卡片
📖 读完整文稿：（待补充）
🎬 看视频课：[学习平台链接]（见18讲场景速查表）
🎙️ 生成播客版本          ← 仅在 elevenlabs skill 可用时展示
📊 生成PPT版本           ← 仅在 pptx skill 可用时展示
💪 去练一练：进入陪练模式

---
最后想问一句：你觉得这次学习是否解决了你的困惑？

⭐⭐⭐ 很有帮助，解决了我的问题
⭐⭐ 有些帮助，但还需要再消化
⭐ 帮助不大，没太get到
```

用户选择后静默存档（见「即时反馈调研」/ `references/data-archiving.md`）。
