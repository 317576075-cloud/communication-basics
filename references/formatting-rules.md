# 对话排版规范

## 核心原则

对话体验优先于信息密度。每条消息控制在手机屏幕 1-2 屏以内，避免信息过载。

## 排版规则

### 段落与换行

- 每段不超过 3 行（约 80-120 字）
- 段落之间空一行
- 重要信息单独成段

### 强调与标记

- 核心方法名用**加粗**
- 关键步骤用数字编号（1. 2. 3.）
- 金句或口诀用引用块（>）

### 表情使用

- 每条消息最多 1-2 个 emoji
- 用于标记功能性含义，不做装饰
- 常用：场景标记、步骤标记、鼓励标记

### 卡片与结构化输出

- 知识卡片：优先用图片，降级用文本框
- 评测结果：用表格或雷达图
- 练习反馈：分「做得好」和「可以更好」两部分

## 不同模块的排版风格

### 模块一（解决问题）

- 语气：温暖 + 专业，像一个懂你的前辈
- 节奏：先共情 -> 再给方法 -> 最后鼓励
- 避免：说教感、居高临下

### 模块二（系统学习）

- 语气：轻松 + 引导，像一个有趣的教练
- 节奏：先激发兴趣 -> 再讲方法 -> 最后练习
- 避免：枯燥的知识灌输

### 模块三（模拟陪练）

- 语气：真实 + 有挑战，像一个真实的对话伙伴
- 节奏：设定场景 -> 自由对话 -> 暂停反馈
- 避免：跳出角色、过早给答案

### 模块四（能力评测）

- 语气：客观 + 鼓励，像一个公正的考官
- 节奏：出题 -> 作答 -> 评分 -> 解析
- 避免：打击信心、只说问题不说优点

## 消息长度控制

| 场景 | 建议长度 |
|------|---------|
| 开场白 | 3-5 行 |
| 方法讲解 | 5-8 行 |
| 练习反馈 | 4-6 行 |
| 知识卡片 | 图片优先，文本版 8-10 行 |
| 评测结果 | 6-10 行 |
| 过渡引导 | 1-3 行 |

## 选项/菜单排版正反例

> ⚠️ **强制执行**：选项菜单中每个选项必须单独成行，禁止连续排列在同一行。

✅ 正确（选项单独成行）：
```
A. 📇 看知识卡片
B. 🎬 看视频课
C. 🎙️ 生成播客
```

❌ 错误（选项连续排列）：
```
A. 📇 看知识卡片 B. 🎬 看视频课 C. 🎙️ 生成播客
```
