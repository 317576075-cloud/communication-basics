# 被动触发规则

**定位**：基于学习进度和行为数据，在对话中主动向用户推荐内容。

> ⚠️ **落地状态说明**：当前 Skill 架构为对话触发，无定时推送系统。下表标注了各触发条件的实际可用性。

## 触发条件与推送内容

| 触发条件 | 推送内容 | 触发逻辑 | 落地状态 |
|---------|---------|----------|----------|
| 完成一个场景练习后 | 下一个关联场景推荐 | 基于学习进度 | ✅ 对话内可用（复盘后自动推荐） |
| 场景速测得分低于 60 分 | 针对性知识卡片 | 基于能力画像 | ✅ 对话内可用（速测后自动推卡片） |
| 连续 5 次主动发起对话 | 能力成长进度播报 | 正向激励 | ⚠️ 需查询 training_records 判断，可近似实现 |
| 上周有学习行为，本周一 14:00 | 本周练习目标推荐 | 周期性推送 | ❌ 需定时推送系统，当前不可用 |
| 7 天无任何交互 | 轻量回归提醒 | 防流失 | ❌ 需定时推送系统，当前不可用 |
| 完成全部 18 讲 | 毕业总结 + 能力雷达图 | 里程碑触发 | ✅ 对话内可用（查 training_records 判断） |

## 场景关联推荐矩阵

当用户完成某个场景后，推荐下一个关联场景：

| 刚完成的场景 | 推荐下一个 | 推荐理由 |
|-------------|-----------|---------|
| 倾听 | 回应 | 听懂了还要接得住 |
| 回应 | 接好任务 | 对齐之后要落地 |
| 接好任务 | 同步汇报 | 接了任务要会汇报 |
| 同步汇报 | 回应批评 | 汇报可能被挑战 |
| 请教求助 | 给TA建议 | 求助和给建议是一对 |
| 说服他人 | 发表不同意见 | 说服力的两面 |
| 进度催办 | 处理冲突 | 催办可能引发冲突 |
| 主动道歉 | 处理冲突 | 道歉是冲突修复的一环 |
| 学会拒绝 | 发表不同意见 | 都需要勇气表达 |
| 破冰 | 识人 | 建立关系后要读懂人 |
| 识人 | 倾听 | 读人之后要听人 |

## 回归提醒话术模板

> ❌ 依赖定时推送系统，当前不可用。保留作为未来接入推送系统时的参考。

当用户 7 天无交互时，发送轻量回归提醒：

```
嘿，好久不见！上次你练习了「{上次场景名}」，表现不错。
最近工作中有没有遇到新的沟通挑战？随时可以来聊聊。

如果你想继续，我推荐试试「{推荐场景名}」—— {推荐理由}。
```

## 里程碑播报模板

当用户完成 5 / 10 / 15 / 18 个场景时触发：

```
恭喜！你已经完成了 {N}/18 个场景的学习。

你的五维能力画像：
{雷达图或文字版能力分布}

最强维度：{最高分维度}
建议加强：{最低分维度}

继续加油，距离全部通关还有 {18-N} 个场景！
```
